# Task Management App (MERN Stack)

A simple Task Management web application built using the **MERN stack** (MongoDB, Express, React, Node.js).

## 📁 Project Structure

```
mern-taskmanagement/
├── backend/       # Node.js + Express + MongoDB (Mongoose)
├── frontend/      # React.js client
├── README.md
└── .gitignore
```

---

## 🚀 Features

- Add new tasks
- View task list
- Mark tasks as complete
- Delete tasks

---

## ⚙️ Technologies Used

### Frontend
- React
- Axios
- Bootstrap / Tailwind (optional)

### Backend
- Node.js
- Express
- MongoDB
- Mongoose

---

## 🛠️ Installation & Running

### Prerequisites

- Node.js & npm
- MongoDB (Ensure `mongod` is running)

---

### 🔧 Backend Setup

```bash
cd backend
npm install
npm start
```

Runs on: `http://localhost:5000`

---

### 🌐 Frontend Setup

```bash
cd frontend
npm install
npm start
```

Runs on: `http://localhost:3000`

---

## 📦 Environment Variables

Create a `.env` file in the `backend/` directory:

```env
PORT=5000
MONGO_URI=mongodb://localhost:27017/taskdb
```
